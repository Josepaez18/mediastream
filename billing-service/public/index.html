Suscripción

Crea una suscripción nueva para una cuenta ya registrada y procesa el primer cobro.

Nueva suscripción

Usa el ID de una cuenta creada en la consola de User (:3001).
Tarjetas de prueba — 4242 4242 4242 4242: pago exitoso · 4000 0000 0000 0002: pago rechazado · cualquier otro número: pago pendiente de confirmación.
Al suscribirse se procesa un único cobro inicial. Si es exitoso, la suscripción queda activa. Si es rechazado, Billing publica payment.failed en RabbitMQ y User-Service restringe la cuenta por su cuenta, sin que Billing lo llame. Si la pasarela no responde a tiempo, el pago queda pendiente en vez de rechazarse.

Cambiar plan

Cambia el plan de una suscripción activa y cobra la diferencia de inmediato.

Cambio de plan

La cuenta debe tener una suscripción activa.
Mismas tarjetas de prueba que en la pestaña "Suscripción".

Aviso de pago

Simula el aviso que la pasarela de pago envía después de un cobro, por ejemplo el de una renovación mensual.

Registrar resultado de un cobro

Usa el ID de suscripción que te devolvió la pestaña "Suscripción".
Cuando el aviso indica un pago rechazado, Billing guarda el pago fallido en su propia base y publica payment.failed en la cola user_service.payment_failed. Para ver la reacción, vuelve a iniciar sesión en la consola de User (:3001): la cuenta aparece MOROSA. Al tercer rechazo queda SUSPENDIDA y ya no puede iniciar sesión.
